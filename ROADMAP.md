# 🗺️ Household OS (Janus) Roadmap

Our mission is to build the world's most capable, elegant, and privacy-conscious open-source estate operating system. This roadmap outlines key milestones and upcoming capabilities.

---

## 📍 Phase 1: v1.0.0 — Initial Open Source Release *(Current)*
- [x] Complete estate command dashboard (HVAC, lighting, irrigation, security).
- [x] Janus voice and text conversational AI with structured tool execution.
- [x] Long-term semantic estate memory powered by PostgreSQL `pgvector`.
- [x] Bi-directional Home Assistant WebSocket synchronization.
- [x] Tesla Fleet API telemetry, charging schedules, and cabin pre-conditioning.
- [x] Hydrology and Pool/Spa controls (iAquaLink / Zodiac).
- [x] Community sports pickup game scheduler and RSVP pipeline.
- [x] Comprehensive Mock Engine for zero-hardware local development.
- [x] Verified zero-secret clean slate with automated Gitleaks pre-commit enforcement.

---

## 📍 Phase 2: Edge Voice & Local AI (Q4 2026)
- [ ] **Zero-Cloud Local Voice Engine**: In-browser WebAssembly Whisper speech-to-text for offline speech recognition.
- [ ] **Custom Wake-Word Detection**: Always-listening edge wake word (*"Hey Janus"*).
- [ ] **First-Class Ollama Tool Calling**: Native local function calling streaming via Qwen 2.5 / Llama 3.3.
- [ ] **Multi-Room Audio Follow-Me**: Automatic Janus voice routing to the smart speaker nearest the resident.

---

## 📍 Phase 3: Hardware Ecosystem Expansion (Q1 2027)
- [ ] **Matter & Thread Gateway**: Direct local device commissioning without requiring external bridges.
- [ ] **Expanded EV Fleet Protocols**: Native cloud and local adapters for Rivian, Ford Pro, and Lucid Air.
- [ ] **Commercial Pool Controllers**: Direct RS-485 / Modbus serial communication for Pentair and Hayward systems.
- [ ] **Smart Irrigation Weather Intelligence**: Evapotranspiration-based automatic watering adjustments using hyper-local weather sensors.

---

## 📍 Phase 4: Companion Mobile Apps & Wearables (Q2 2027)
- [ ] **iOS & Android Native Companion**: Built with React Native / Expo.
- [ ] **Apple Watch & Wear OS Complications**: Quick-action complications for opening estate gates, arming security, or pre-heating the spa.
- [ ] **Digital Car Key & NFC Gate Access**: Ultra-Wideband (UWB) and geofenced automated estate arrival routines.
